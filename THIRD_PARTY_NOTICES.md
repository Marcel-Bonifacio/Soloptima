Soloptima bundles the libraries and fonts below in `web/vendor/`. Each keeps its own licence, reproduced here as its terms require. The Soloptima licence (`LICENSE.md`) does not apply to them.

| Component | Version | Licence | Source |
|---|---|---|---|
| Leaflet | 1.9.4 | BSD 2-Clause | https://leafletjs.com |
| Leaflet-Geoman (free) | 2.17.0 | MIT | https://github.com/geoman-io/leaflet-geoman |

| tz-lookup (`@photostructure/tz-lookup`) | 11.7.0 | CC0 1.0 Universal; zone data ODbL 1.0 | https://github.com/photostructure/tz-lookup |
| Geist and Geist Mono fonts | 1.200 | SIL Open Font License 1.1 | https://github.com/vercel/geist-font |

Plotly.js and Leaflet-Geoman are bundles that contain other open-source packages; their licences follow under "Packages inside plotly.min.js and leaflet-geoman.min.js".

The macOS build links the system libcurl. The Windows build uses the system WinHTTP library and is statically linked with GCC's libgcc and libstdc++ (GPL-3.0 with the GCC Runtime Library Exception, which requires no notice) and with the MinGW-w64 runtime, including winpthreads, whose notices follow.
